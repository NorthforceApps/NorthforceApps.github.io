# northforceapps.com

User GitHub Pages site for **Northforce Apps**. This repo must be named
`NorthforceApps.github.io`. The `CNAME` file binds the apex domain; project
sites (`gpslogger`, `cue-loop`, `remotemic`, `webcam`) then appear at
`https://northforceapps.com/<repo>/`.

Do not put a `CNAME` in those project repos.
